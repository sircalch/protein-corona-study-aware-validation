## Source chain and interpretation

LITERATURE: Canchola et al. [ACS Nano 2025](https://doi.org/10.1021/acsnano.5c08608), prediction-methods section, and [official Supporting Information, Table S5](https://acs.figshare.com/articles/journal_contribution/30256369) describe presence/absence for all four targets. The paper specifies Present=0 and Absent=1. It does not specify a numerical threshold for generating the prepared classification CSV. The Supplement's complement detection frequency is 94.3%, distinct from the prepared classification column.

The original Python script and all three retrievable notebook versions load already-labeled input, drop rows with pandas missing values, and encode Present=0 / Absent=1. They do not build those labels from the quantitative table. README documents the modeling and data resources, not that missing conversion. The only published version in the prediction CSV path history is byte-identical to our preserved file. The initial repository tree contains scripts under Datasets, not an older labeled CSV. The main branch has 19 commits and no tags; no unobserved/private history is claimed inspected. One deleted notebook revision correctly returns 404. A metadata-history request returned 504; retry identified its upload commit. All retrieved code/versions and request failures are preserved in evidence/label_audit.

Two other original scripts have different rules: Protein_Frequency.R uses value > 0 and averages with na.rm=TRUE; Meta-Analysis_for_Protein_Corona.R uses !is.na(v) & v != 0 & v != 'ND'. Neither script generates the prediction CSV. These rules cannot be silently substituted for published model labels.

The notebook's interactive protein_predict helper labels predict_proba[:,1] as probability of PRESENT even though class 1 is ABSENT. This display inconsistency is separate from the unexplained label construction and does not establish its cause. Our benchmark uses p(class 1)=p(audited detection).

## Measurement qualification

The quantitative table mixes units, including log2 intensity. Positive-value detection follows the frozen source-frequency rule, not a universal detection limit; zero in log units need not mathematically mean absence. The five log-unit rows are retained in the primary analysis, with exclusion of the whole affected studies specified as a sensitivity before LOSO. Source-level unknowns remain missing. No imputed absence and no physical adsorption/binding claim is authorized.
