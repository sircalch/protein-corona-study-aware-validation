# Minimal benchmark lock — before model fitting

2026-09-06. GREEN. All numeric settings below are **PLAN design choices**, not literature measurements; exceptions explicitly reference published code. No hyperparameter search.

- [PLAN] Task: predict **reported detection** (quantitative entry > 0) in human corona profiles, not physical adsorption affinity. Numeric zero = not reported detected in the curated assay; unknown/non-numeric remains unknown and is excluded per target. Source matrix proteins: Apolipoprotein E, Apolipoprotein B-100, Complement C3, Clusterin. Fixed panel comes from Canchola; no global prevalence-based target selection.
- [PLAN] Main model: L2 logistic regression, C=1, max_iter=2000, no class balancing. Secondary: RF, 100 trees, min_samples_leaf=5, n_jobs=1; XGBoost optional secondary after baseline reproduction. Eight source categorical features, one-hot categories learned on training only. No protein outcomes, DOI, ID, study, year, proteomics yield or test preprocessing as predictors.
- [PLAN] Primary endpoint: mean of per-study Brier scores, then equal weight across the four proteins. Define M = −Brier and ΔM = Brier_GROUP − Brier_RANDOM; positive means worse OOD performance, no sign presumed. AUROC/AP/balanced accuracy are secondary; single-class study AUROC undefined, retained as NA, never zero. Report per-study support and calibration bins; no post-hoc calibration on test.
- [PLAN] Controls: training-only prevalence predictor; LR versus RF; RANDOM versus GROUP_STUDY with the same eligible evaluation cohort, fixed hyperparameters and common training-size cap. Exact duplicate source observations are kept in a single component for leakage-safe splits; RANDOM is explicitly a sample-split diagnostic. Matched-size comparison subsamples training rows only, independent of outcomes. Residual shifts in class balance and train-study composition are part of the split effect, not separately causal batch estimates.
- [PLAN] Split seeds: 32, 1729, 2026. Seed 32 also matches the published reproduction code. Five outer folds per regime. All split manifests written before the first scientific fit. No inner CV is required for fixed models. Preprocessing never fits on held-out rows. A separate temporal latest-year holdout is reserved and NOT scored in this first run. LOSO and material holdout manifests are prepared but not trained initially.
- [PLAN] Exclusions: nonhuman entries; missing study/sample ID; missing or nonnumeric target; no arbitrary deletion of uncommon materials. Missing feature categories are represented explicitly. Shared-study or identical-observation components cannot straddle GROUP/LOSO/temporal/material partitions. Source DOI anomalies are quarantined, not silently repaired by guessing.
- [PLAN] Uncertainty: paired bootstrap of independent study components, 2000 resamples, seed 2026; confidence interval 2.5–97.5 percentiles. Average seeds within each study/target first; do not count seeds as independent studies. Bootstrap covers between-study sampling conditional on fitted models, not the complete uncertainty of model retraining. Cluster components are the resampling unit when studies are linked by identical observations.
- [PLAN] Validity checks: train/test disjoint rows; disjoint study/components for GROUP; no exact observation overlap for leakage-safe splits; all out-of-fold eligible rows predicted exactly once per seed; convergence warnings logged and cause invalidation for the affected fit. No comparisons interpreted before reproduction passes.
- [PLAN] Baseline reproduction is a separate compatibility branch using the published 581-row prepared file, label convention Present=0/Absent=1, published split seed 32/test fraction 0.3, SMOTE and the published fixed RF hyperparameters. It does not correct published labels or count as the audited OOD result. Reproduce test metrics at the four-decimal precision printed in the authors' notebook; discrepancies remain visible. No tuning to match them.
- [UNKNOWN] Dataset labels/DOI audit may reveal additional defects. Evidence-supported deterministic repair is permitted before fitting; unresolved target semantics are excluded and documented rather than converted into favorable results. No Results manuscript or synthetic scientific data.
